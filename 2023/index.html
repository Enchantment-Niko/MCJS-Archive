MC.js收录了在GitHub上的优秀开源网页MC项目，并提供使用JavaScript制作的各种网页MC的最佳Web版本。MC.JS永久免费，无广告，无各种认证，即开即玩，优化中文版本，服务于国人玩家。

[仅限电脑版]网页Minecraft1.8.8

EaglercraftX 1.8.8 反编译版本。游戏内容基本与Minecraft Java 1.8.8原版一致，只支持电脑版，网页游玩性能比Java版差一点点。
注意：MC.js内置有联机服务器，如果连接失败，请多刷新几次即可连接。网页版MC1.8.8只支持服务器多人游戏。

建议使用Google Chrome浏览器访问，Chrome下游戏性能最好。
